01 Tokens

One disciplined token system, not ad-hoc chrome styling.

All surfaces should pull from the same shell grammar: graphite depth, restrained accent, quiet borders, and motion that confirms structure instead of decorating it.

top bar, dock, shell chrome

02–08 Surface Roadmap

Redesign sequence and implementation-first handoff.

This file should be reconstructed in Figma page by page, then pulled back into echOS with MCP node queries. The first code parity target is Terminal window chrome, followed by Top Bar, Dock, Quick Settings, and Overview.

02 Desktop

Idle desktop, one-terminal desktop, two-window desktop. Launcher closed. Strong central calm.

03 Window Chrome

Focused terminal, inactive terminal, floating utility, modal. One chrome language.

04 Launcher + Palette

Split app launcher from command palette. Remove management-console tone.

05 Overview

Spatial workspace cards, layout and count, selected workspace calm emphasis.

06 Quick + Notify

Grouped quick settings, lighter notifications, shared shell language.

07 Motion

Overlay enter/exit, workspace switch, focus shift, open/close timing.

08 Handoff

Node naming, token callouts, spacing annotations, implementation-ready states.
